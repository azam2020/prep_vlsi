Chapter 1: Digital Electronics — Part 4 (Q151 to Q200)

Finite State Machines, Clock Dividers, Hazards, and Advanced Numericals

12. Finite State Machines (Moore & Mealy)

Q151 What is the fundamental difference between a Moore and a Mealy Machine?

Answer:
• Moore Machine: The output depends strictly on the current state.
• Mealy Machine: The output depends on the current state AND the current inputs.

Q152 Which FSM (Moore or Mealy) generally requires fewer states to implement the same logic?

Answer: Mealy. Because the output can change based on the input transition before the state actually updates on the clock edge, a Mealy machine can often merge the "final" state into the preceding state's transition, saving one or more flip-flops.

Q153 What is the fatal flaw of a pure Mealy Machine output?

Answer: Glitches. Because the output is directly connected to combinational inputs, if the input bounces or glitches between clock cycles, the Mealy output will immediately glitch as well, propagating false logic to downstream circuits.

Q154 How do you fix the Mealy Machine glitch problem in industry?

Answer: By using a Registered Mealy Machine. You insert a flip-flop at the output of the Mealy combinational logic. This absorbs the glitches and synchronizes the output, though it delays the output response by exactly one clock cycle.

Q155 Numerical How many states are required to design a Sequence Detector for an N-bit pattern using a Moore machine?

Answer: N + 1 states. A Moore machine requires an extra dedicated "Success" state at the very end just to assert the output HIGH.

Q156 Numerical How many states are required to design a Sequence Detector for an N-bit pattern using a Mealy machine?

Answer: N states. A Mealy machine asserts the output HIGH during the transition from the $(N-1)^{th}$ state when it sees the final correct input, eliminating the need for a final resting state.

Q157 What is the difference between an Overlapping and Non-Overlapping sequence detector?

Answer: For a pattern like "101":
• Non-Overlapping: In the sequence 10101, it detects exactly ONE instance. It consumes the bits and starts fresh.
• Overlapping: In the sequence 10101, it detects TWO instances (the middle '1' serves as the end of the first pattern and the start of the second pattern).

Q158 Name the three common FSM State Encoding techniques.

Answer:
1. Binary (Sequential): 00, 01, 10, 11 (Uses min FFs, complex combinational decoding).
2. Gray Code: 00, 01, 11, 10 (Only 1 bit changes per state, safe for crossing clock domains).
3. One-Hot: 0001, 0010, 0100, 1000 (Uses max FFs, but next-state decoding is extremely fast and simple).

Q159 Why do FPGA designers almost exclusively use One-Hot encoding?

Answer: FPGAs are incredibly "Flip-Flop rich" but have limited combinational logic depth per LUT. One-Hot uses many flip-flops (which FPGAs have in abundance) but drastically simplifies the next-state logic, allowing the FSM to run at much higher clock frequencies.

Q160 What is an Unreachable State, and how do you handle it safely?

Answer: An Unreachable State is a valid flip-flop combination that isn't part of the FSM diagram (e.g., state 111 in a 5-state machine). If a cosmic ray or power glitch knocks the FSM into this state, it can lock up. A "Safe FSM" routes all unused states back to the IDLE/RESET state unconditionally.

13. Clock Dividers & Generators

Q161 Whiteboard How do you build a Divide-by-2 clock divider?

Answer: Use a single D-Flip-Flop. Connect the $\bar{Q}$ output directly back into the $D$ input. It toggles on every rising edge, producing a perfect 50% duty cycle clock at half the frequency.

Q162 Whiteboard How do you build a Divide-by-4 clock divider?

Answer: Cascade two Divide-by-2 circuits. Connect the $Q$ output of the first D-FF into the clock ($CLK$) pin of the second D-FF.

Q163 Tricky What is the danger of cascading flip-flops to build clock dividers (Ripple dividers) in ASICs?

Answer: Clock Skew. The output of the second flip-flop will be delayed by the $T_{cq}$ of the first flip-flop. The divided clock is no longer phase-aligned with the root clock, making synchronous data transfers between the two clock domains fail Hold-Time checks. ASIC designers prefer synchronous enable counters instead of physically dividing the clock.

Divide by 3 (50% Duty Cycle) Architecture

A standard Mod-3 yields 33% duty cycle. The OR gate with a NegEdge sampled signal stretches it to 50%.

Q164 Whiteboard How do you build a Divide-by-3 clock divider with an exact 50% Duty Cycle?

Answer:
1. Build a standard Mod-3 counter (states 00, 01, 10) driven by the Rising Edge of the clock. Take the MSB ($Q_A$). This gives a 33% duty cycle.
2. Pass $Q_A$ into a D-Flip-Flop driven by the Falling Edge of the clock. This creates a version of $Q_A$ shifted by exactly 0.5 clock cycles ($Q_B$).
3. Pass both signals into an OR gate ($Q_A + Q_B$). The resulting output stretches the 33% pulse perfectly to 50%.

Q165 How do you build a Fractional Clock Divider (e.g., Divide by 1.5)?

Answer: To divide by 1.5, you need an output edge every 1.5 input cycles. This requires exploiting both the rising and falling edges of the source clock using an XOR gate, or utilizing a PLL (Phase Locked Loop) which can multiply the clock by 2 and then divide by 3.

Q166 What is a Glitch-Free Clock Gating circuit?

Answer: If you use a simple AND gate to gate a clock ($CLK \text{ AND } EN$), the $EN$ signal might transition from 1 to 0 while the clock is High, instantly chopping the clock pulse in half (a glitch). A glitch-free gater uses a Negative Level-Sensitive Latch on the $EN$ signal before the AND gate. The latch ensures $EN$ can only change state when the clock is safely Low.

14. Hazards, Glitches & Metastability

Q167 What is a Static-1 Hazard?

Answer: The output of a combinational circuit is supposed to remain safely at Logic 1. However, due to unequal propagation delays through different gates, the output momentarily dips to Logic 0 before recovering to 1.

Q168 How do you eliminate a Static-1 Hazard?

Answer: On a K-Map, this hazard occurs when an input transition moves between two adjacent but separate groupings (implicants). You fix it by adding a redundant Consensus Term (drawing an extra circle that overlaps the two groups) so the output is held high by the redundant logic during the transition.

Q169 What is a Dynamic Hazard?

Answer: When an output is supposed to transition exactly once (e.g., from 0 to 1), but instead bounces multiple times ($0 \rightarrow 1 \rightarrow 0 \rightarrow 1$) before settling. This only occurs in multi-level logic circuits (3 or more levels of gates) with converging paths of vastly different delays.

Q170 Does a Flip-Flop eliminate combinational hazards?

Answer: Yes. Because a flip-flop only samples data exactly at the clock edge, any static or dynamic glitches that occur between clock edges are completely ignored (as long as they settle before the Setup window opens).

Q171 What is Metastability?

Answer: When a Flip-Flop's Setup or Hold time is violated, the internal cross-coupled inverters fail to resolve to a strong 0 or 1. The output hovers at an intermediate voltage ($\sim V_{DD}/2$) for an unpredictable duration before thermal noise finally knocks it into a stable random state.

Q172 Write the MTBF (Mean Time Between Failures) equation for Metastability.
$MTBF = \frac{e^{t_r / \tau}}{T_0 \cdot f_{clk} \cdot f_{data}}$

Notice the exponential term. The only way to meaningfully fix metastability is to increase the resolution time ($t_r$) by adding a second synchronizing flip-flop.

15. Advanced Interview Numericals

Q173 Numerical A sequence detector must detect "1101". It is implemented as a Mealy machine. How many states are required?

Answer: Sequence length $N = 4$. A Mealy machine requires $N$ states. Therefore, 4 states.

Q174 Numerical How many Flip-Flops are needed to encode those 4 states?

Answer: Using binary encoding, $2^K \ge States$. For 4 states, $2^2 = 4$. Therefore, 2 Flip-Flops are required. (If One-Hot encoded, 4 FFs would be required).

Q175 Numerical A Ring Oscillator is built using 5 inverters. Each inverter has a delay of 200ps. What is the frequency of oscillation?

Answer:
$f = \frac{1}{2 \cdot N \cdot t_{pd}}$
$f = \frac{1}{2 \cdot 5 \cdot 200ps} = \frac{1}{2000ps} = \frac{1}{2ns}$
Frequency = 500 MHz.

Q176 Numerical A 10-bit Ring Counter operates at 100 MHz. What is the frequency of the pulse observed at the $Q$ output of any single flip-flop?

Answer: A Ring Counter circulates a single '1' bit through $N$ flip-flops. Therefore, the '1' visits a specific flip-flop exactly once every $N$ clock cycles.
$F_{out} = \frac{100 \text{ MHz}}{10} = \mathbf{10 \text{ MHz}}$.

Q177 Numerical You need to implement the boolean function $F(A,B,C) = \Sigma m(0,2,4,6)$ using a MUX. If $A$ and $B$ are connected to the select lines ($S_1, S_0$), what must the data inputs ($I_0, I_1, I_2, I_3$) be connected to?

Answer: Use a Truth Table. The minterms 0, 2, 4, 6 correspond to $A,B,C$ states: 000, 010, 100, 110.
Notice that in all these cases, $C$ must be 0 for $F$ to be 1.
If $A=0, B=0$ (Select 0): $F=1$ only if $C=0$. So $I_0 = C'$.
If $A=0, B=1$ (Select 1): $F=1$ only if $C=0$. So $I_1 = C'$.
By expanding, all inputs $I_0, I_1, I_2, I_3$ must be connected to exactly $C'$.

Shortcut: As proven in Q47, $\Sigma m(0,2,4,6)$ mathematically simplifies to $C'$. The entire MUX is technically redundant!
Q178 How do you convert a SR Flip-Flop to a T Flip-Flop?

Answer: Connect an AND gate to $S$ ($S = T \cdot \bar{Q}$). Connect an AND gate to $R$ ($R = T \cdot Q$).

Q179 What is a Gray Code counter, and why is it used?

Answer: A counter where only one bit flips per state transition. It is mandatory for Asynchronous FIFO pointers because passing binary counters across clock domains via synchronizers causes multi-bit skew failure.

Q180 Why is Binary Coded Decimal (BCD) used instead of pure Binary?

Answer: It makes driving 7-segment digital displays incredibly easy. A 4-bit nibble represents exactly one human-readable decimal digit (0-9). However, it is highly inefficient for storage (wastes 6 states per nibble).

Q181 Convert decimal -5 to 4-bit 2's complement.

Answer:
1. Binary of +5 = `0101`
2. Invert all bits (1's comp) = `1010`
3. Add 1 = `1011`

Q182 Extend the 4-bit 2's complement number `1011` (-5) to 8 bits.

Answer: Sign Extension. Copy the MSB (the sign bit, 1) to all higher bits.
Result: `1111_1011`.

Q183 What is the range of an N-bit 2's complement number?

Answer: $-2^{(N-1)}$ to $(2^{(N-1)} - 1)$.
For 8 bits: -128 to +127.

Q184 What happens when you add +127 and +1 in an 8-bit signed system?

Answer: Overflow. `0111_1111` + `0000_0001` = `1000_0000`. The MSB became a 1, which the system interprets as a negative number (-128). Two positive numbers added together yielded a negative number.

Q185 How do you detect an Overflow in a signed adder?

Answer: XOR the carry-in of the MSB with the carry-out of the MSB. If they differ, an overflow occurred. $Overflow = C_{in\_MSB} \oplus C_{out\_MSB}$.

Q186 Can you implement a Flip-Flop using a 2:1 MUX?

Answer: Yes, but it requires two MUXes (Master-Slave setup). The first MUX selects between Data and Feedback based on the inverted clock. The second MUX selects between Master output and Feedback based on the clock.

Q187 If $A=1010$ and $B=1100$, what is the Bitwise AND, OR, and XOR?

Answer:
• AND: 1000
• OR: 1110
• XOR: 0110

Q188 What is an LFSR used for?

Answer: Linear Feedback Shift Register. Used for generating Pseudo-Random Binary Sequences (PRBS), CRC (Cyclic Redundancy Checks) in ethernet packets, and built-in self-test (BIST) pattern generation.

Q189 What is a Barrel Shifter?

Answer: A purely combinational logic circuit (built using layers of MUXes) that can shift or rotate a data word by an arbitrary number of bits in a single clock cycle, unlike a sequential shift register which takes N clock cycles.

Q190 What is the advantage of a Carry Select Adder over a Ripple Carry Adder?

Answer: It pre-computes the sum twice for the upper bits: once assuming the incoming carry is 0, and once assuming it is 1. When the actual carry arrives from the lower bits, a MUX simply selects the correct pre-computed answer instantly, drastically cutting propagation delay.

Q191 What is the advantage of a Wallace Tree multiplier?

Answer: It uses an array of Carry Save Adders (CSAs) to sum the partial products of a multiplication entirely in parallel. It reduces the height of the addition matrix from $O(N)$ to $O(\log N)$, making it significantly faster than an array multiplier.

Q192 Can a Decoder be built using Demultiplexers?

Answer: Yes. A Demultiplexer is functionally identical to a Decoder. Tie the Demux data input (Enable) to Logic 1, and use the Select lines as the Address inputs.

Q193 Is NAND logic associative?

Answer: NO. $(A \text{ NAND } B) \text{ NAND } C \ne A \text{ NAND } (B \text{ NAND } C)$. This is why synthesizing logic to NAND gates requires careful tool algorithms; you cannot freely rearrange the hierarchy like you can with AND gates.

Q194 What does a XOR gate with one input tied to VDD (1) do?

Answer: It acts as an Inverter (NOT gate). $A \oplus 1 = A'$.

Q195 What does an XOR gate with one input tied to GND (0) do?

Answer: It acts as a Buffer. $A \oplus 0 = A$.

Q196 What is a Mealy machine's behavior during a reset?

Answer: When reset is asserted, the FSM state goes to 0 (IDLE). However, because Mealy outputs depend on inputs, if the inputs are active during the reset cycle, the Mealy machine can still output a 1! The output is not inherently shielded by the state reset.

Q197 What happens if you connect the Q output of a D-Flip Flop to the D input without an inverter?

Answer: It acts as a static latch. Whatever state it initialized in, it feeds back into itself on every clock edge, holding that exact state forever.

Q198 What happens if you violate the Setup time of a Shift Register?

Answer: The first flip-flop goes metastable and samples a random value. On the next clock cycle, that incorrect value is securely shifted into the second flip-flop. The data stream is permanently corrupted.

Q199 What is a Bidirectional shift register?

Answer: A register that can shift data to the left or to the right. It requires a 2:1 MUX at the input of every flip-flop to select whether the $D$ input comes from the $Q$ of the left neighbor or the $Q$ of the right neighbor, controlled by a Dir pin.

Q200 The Final Test: Why is VLSI predominantly built on Synchronous Logic rather than Asynchronous Logic?

Answer: Asynchronous logic (unclocked logic reacting instantly to data changes) is theoretically faster and burns less power. However, it requires insane "handshaking" protocols to ensure data arrives in order, and it is almost impossible for CAD tools to verify setup/hold timing mathematically. Synchronous logic (using a global clock) provides absolute determinism. The clock acts as a rigid synchronization barrier, making design, STA verification, and testing achievable at the scale of 50 billion transistors.
