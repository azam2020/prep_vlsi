9. Memories in Digital Logic

Definition Circuits designed to store large arrays of binary data, accessed via address buses.

Simple Explanation Using flip-flops to store 1 Megabyte of data is like writing a book on individual sticky notes. Memory blocks (RAM/ROM) are the bound books and filing cabinets—much denser and cheaper.

TypeArchitectureSpeedDensityPrimary Use in SoC
SRAM 6 Transistors per cell. No refresh needed. Very Fast Low (Bulky) CPU Cache (L1, L2), Registers
DRAM 1 Transistor + 1 Capacitor. Must be refreshed. Slower High (Dense) Main System Memory
ROM Hardwired connections (usually 1 Transistor). Fast Read Very High Bootloaders, Lookup Tables
Real Interview Tip: If asked "How is a ROM fundamentally built?", tell them it is essentially a Decoder connected to an array of OR gates. The address goes into the decoder, and the hardwired connections map the minterms to the output bits.

10. FSM State Encoding Techniques

Technical Explanation How you represent the "states" of your FSM in binary significantly impacts the speed and area of your synthesized circuit.

Binary Encoding

States: 00, 01, 10, 11

  • Uses the minimum number of Flip-Flops (\( \log_2(N) \)).
  • Requires complex combinational logic to decode next states.
  • Best for: Area-constrained designs.
Gray Encoding

States: 00, 01, 11, 10

  • Only 1 bit changes per state transition.
  • Eliminates intermediate glitching states.
  • Best for: Low power, or passing states across clock domains (CDC).
One-Hot Encoding

States: 0001, 0010, 0100, 1000

  • Uses N Flip-Flops for N states.
  • Next-state logic is incredibly simple (just 2-input gates).
  • Best for: FPGAs and high-speed designs where combinational delay must be minimized.
The Interview Scenario

Interviewer: "When writing an FSM in Verilog, what is the industry standard coding style?"

Your Satisfying Answer: "The industry standard is the 3-Always Block architecture.
1. A sequential always @(posedge clk) block dedicated solely to updating the current state to the next state.
2. A combinational always @(*) block that calculates the next_state based on current_state and inputs.
3. A third block (combinational or sequential) to calculate the outputs.
This separates memory from logic, preventing unintended latches and making the RTL readable and easy for synthesis tools to optimize."

Common Mistake: Writing FSMs with only one giant `always` block that mixes next-state calculations, output assignments, and clock edges. This leads to spaghetti code and makes it impossible to register outputs cleanly.

11. Top Interview Numericals

Interviewers will ask you to calculate max frequencies and propagation delays to test if you actually understand how hardware physically behaves.

Numerical 1: Maximum Clock Frequency

Question: Two Flip-Flops (FF1 and FF2) are connected in series with combinational logic between them.
- FF Clock-to-Q delay (\( T_{cq} \)) = 2 ns
- Combinational Logic delay (\( T_{comb} \)) = 5 ns
- FF Setup Time (\( T_{setup} \)) = 1 ns
- FF Hold Time (\( T_{hold} \)) = 0.5 ns
What is the maximum clock frequency at which this circuit can operate safely?

Solution:
To avoid setup time violations, the clock period (\( T_{clk} \)) must be greater than the total delay of the data path.
Equation: \( T_{clk} \ge T_{cq} + T_{comb} + T_{setup} \)
\( T_{clk} \ge 2\text{ns} + 5\text{ns} + 1\text{ns} \)
\( T_{clk} \ge 8\text{ns} \)

Maximum Frequency \( f_{max} = \frac{1}{T_{clk}} = \frac{1}{8 \times 10^{-9}} \) = 125 MHz.

Note: The hold time parameter is a distractor here. Hold time is checked against the shortest path, not the clock period.

Numerical 2: Modulo Counters

Question: You need to design a circuit that divides a 100 MHz clock down to a 1 MHz clock. How many Flip-Flops are required to build this counter?

Solution:
1. Calculate the division ratio: \( \frac{100\text{ MHz}}{1\text{ MHz}} = 100 \).
2. We need a Mod-100 counter (a counter that counts from 0 to 99).
3. The formula for the number of flip-flops (\( N \)) required is: \( 2^N \ge \text{Modulus} \).
4. \( 2^6 = 64 \) (Too small).
5. \( 2^7 = 128 \) (Sufficient).
Answer: 7 Flip-Flops.

Numerical 3: Sequence Detectors

Question: How many states are required in a state diagram to detect the sequence "1101" for a Moore machine vs. a Mealy machine?

Solution:
Let \( N \) be the length of the sequence (\( N = 4 \)).
- A Moore machine requires \( N + 1 \) states. (Answer: 5 states). It needs a final state just to assert the output HIGH.
- A Mealy machine requires \( N \) states. (Answer: 4 states). It asserts the output HIGH during the transition from state 3 to state 1 upon receiving the final '1'.
