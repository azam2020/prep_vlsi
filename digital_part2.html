Chapter 1: Digital Electronics (Part 2/4)

Multiplexers, Demultiplexers, Encoders, and Decoders

4. Multiplexers (MUX) & Demultiplexers (DEMUX)

Definition A MUX routes one of \( 2^N \) input lines to a single output line based on \( N \) select lines. A DEMUX does the reverse, taking one input and routing it to one of \( 2^N \) outputs.

Simple Explanation A MUX is a digital switchboard operator. Multiple people (inputs) are trying to make a call, but there is only one telephone line (output). The operator (select lines) decides who gets to use the line. A DEMUX is when one person is calling in, and the operator connects them to the right extension.

Technical Explanation The MUX is a universal combinational circuit. A \( 2^n:1 \) MUX can implement ANY boolean function of \( n+1 \) variables. The boolean equation for a 2:1 MUX is \( Y = S'I_0 + S I_1 \). In modern FPGA architectures, Look-Up Tables (LUTs) are essentially SRAMs paired with large multiplexers to implement logic.

4:1 MUX Architecture
Verilog Implementation (4:1 MUX)
module mux4to1 (
    input [3:0] in,
    input [1:0] sel,
    output reg y
);
    // Behavioral modeling using case
    always @(*) begin
        case(sel)
            2'b00: y = in[0];
            2'b01: y = in[1];
            2'b10: y = in[2];
            2'b11: y = in[3];
            default: y = 1'bx;
        endcase
    end
endmodule
The Interview Scenario

Interviewer: "How can you implement a 2-input XOR gate using a 2:1 MUX?"

Your Satisfying Answer: "The boolean equation for a 2-input XOR is \( Y = A \oplus B = A'B + AB' \). The standard equation for a 2:1 MUX is \( Y = S'I_0 + SI_1 \).

If we use A as the select line (\( S = A \)), the equation becomes \( Y = A'I_0 + AI_1 \). By comparing the two equations, we can map \( I_0 = B \) and \( I_1 = B' \). So, connect A to the select pin, B to the \( I_0 \) pin, and an inverted B (which requires a NOT gate) to the \( I_1 \) pin."

Follow-up Q: "What if I told you that you have NO logic gates at all—only 2:1 multiplexers. How do you invert B for that \( I_1 \) pin?"

Answer: "I can create an inverter using another 2:1 MUX. To make a NOT gate for B, I connect B to the select line of a second MUX. I tie \( I_0 \) to VDD (logic 1) and \( I_1 \) to GND (logic 0). The output is \( B'(1) + B(0) = B' \). I then feed this into \( I_1 \) of the first MUX."

Common Mistake: Trying to draw truth tables and K-maps during the interview to solve MUX implementation questions. Use Shannon's Expansion (the algebraic method shown above) instead—it's 10x faster and less prone to arithmetic errors under pressure.

5. Encoders & Decoders

Definition A Decoder converts an N-bit binary code into up to \( 2^N \) unique output lines (Binary to One-Hot). An Encoder does the reverse, converting \( 2^N \) input lines (where only one is active) into an N-bit binary code (One-Hot to Binary).

FunctionTranslates address/code to a specific lineTranslates active line to a binary code

The Priority Encoder

Technical Explanation A standard encoder breaks if two inputs are logic HIGH simultaneously. A Priority Encoder solves this by assigning a hierarchy to the inputs. If multiple inputs are high, it outputs the binary code of the input with the highest priority. This is the exact digital circuit used inside CPUs to handle hardware interrupts (e.g., a Power Failure interrupt has higher priority than a Keyboard interrupt).

The Interview Scenario

Interviewer: "How would you implement a Full Adder circuit using a Decoder and minimum additional gates?"

Your Satisfying Answer: "A Full Adder has 3 inputs (A, B, Cin) and 2 outputs (Sum, Cout). Because it has 3 inputs, I will use a 3-to-8 Decoder. A Decoder naturally generates all possible minterms of its inputs (0 through 7).

From the truth table of a Full Adder:
Sum = \(\Sigma m(1, 2, 4, 7)\)
Cout = \(\Sigma m(3, 5, 6, 7)\)

So, I simply take the output lines 1, 2, 4, and 7 from the decoder and feed them into a 4-input OR gate for the Sum. I take output lines 3, 5, 6, and 7 and feed them into another 4-input OR gate for Cout. It takes exactly one 3:8 decoder and two 4-input OR gates."

Verilog: 4:2 Priority Encoder
module priority_encoder (
    input [3:0] in,
    output reg [1:0] out,
    output reg valid
);
    // Highest index has priority
    always @(*) begin
        valid = 1'b1;
        casex(in)
            4'b1xxx: out = 2'd3;
            4'b01xx: out = 2'd2;
            4'b001x: out = 2'd1;
            4'b0001: out = 2'd0;
            default: begin
                out = 2'd0;
                valid = 1'b0;
            end
        endcase
    end
endmodule
Real Interview Tip: Notice the casex in the Verilog code? Interviewers love asking about case, casex, and casez. casex treats 'x' and 'z' as don't cares, which perfectly maps to priority encoder logic in simulation, but casez is generally preferred for synthesis to avoid matching literal unknown 'x' states in RTL.
