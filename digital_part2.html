Chapter 1: Digital Electronics — Part 2 (Q51 to Q100)

Multiplexers, Encoders, Decoders, and Arithmetic Circuits

4. Multiplexers (MUX) & Demultiplexers

Q51 What is a Multiplexer (MUX)?

Answer: A MUX is a digital switch or data selector. It takes $2^N$ input lines and routes exactly one of them to a single output line, based on the binary value of $N$ select lines.

Q52 Write the Boolean equation for a 2:1 MUX.
$Y = S'I_0 + S I_1$

Where $S$ is the select line, and $I_0, I_1$ are the data inputs.

Q53 Why is a MUX considered a "Universal Combinational Circuit"?

Answer: Because a $2^N:1$ MUX can be used to implement any boolean function of $N+1$ variables, without needing any other logic gates (except occasionally an inverter for the inputs). FPGAs use this principle; their Look-Up Tables (LUTs) are essentially massive MUXes driven by SRAM cells.

2:1 MUX Symbol & Hardware
Q54 Whiteboard How do you implement a NOT gate using a 2:1 MUX?

Answer: Connect the input signal $A$ to the Select line ($S=A$).
Connect $I_0 = 1$ (VDD).
Connect $I_1 = 0$ (GND).
Equation: $Y = A'(1) + A(0) = A'$.

Q55 How do you implement an AND gate using a 2:1 MUX?

Answer: Connect $A$ to the Select line ($S=A$).
Connect $I_0 = 0$ (GND).
Connect $I_1 = B$.
Equation: $Y = A'(0) + A(B) = A \cdot B$.

Q56 How do you implement an OR gate using a 2:1 MUX?

Answer: Connect $A$ to the Select line ($S=A$).
Connect $I_0 = B$.
Connect $I_1 = 1$ (VDD).
Equation: $Y = A'(B) + A(1) = A'B + A = A + B$.

Q57 Tricky How do you implement an XOR gate using a 2:1 MUX?

Answer: The XOR equation is $Y = A'B + AB'$.
Connect $A$ to the Select line ($S=A$).
Connect $I_0 = B$.
Connect $I_1 = B'$. (Requires a NOT gate to invert B).
If no NOT gate is allowed, use a second 2:1 MUX to generate $B'$.

Q58 What is the formula for calculating how many $2:1$ MUXes are required to build an $N:1$ MUX?
$\text{Total 2:1 MUXes} = N - 1$

For example, a $4:1$ MUX requires $(4-1) = 3$ MUXes. An $8:1$ MUX requires $7$ MUXes.

Q59 How do you build an $8:1$ MUX using only $4:1$ MUXes and a $2:1$ MUX?

Answer:
1. Connect inputs $D_0-D_3$ to the first $4:1$ MUX.
2. Connect inputs $D_4-D_7$ to the second $4:1$ MUX.
3. Connect the lower 2 select lines ($S_0, S_1$) to BOTH $4:1$ MUXes.
4. Feed the two outputs into a $2:1$ MUX, controlled by the MSB select line ($S_2$).

Q60 Tricky How do you use a 2:1 MUX to create a Level-Sensitive D-Latch?

Answer: Connect the Clock to the Select line ($S=Clk$).
Connect the Data (D) to $I_1$.
Connect the Output Y back to $I_0$ (Feedback loop!).
When $Clk=1$, $Y = D$ (Transparent). When $Clk=0$, $Y = Y$ (Holds previous state).

Trap: This forms a combinational loop. It works logically, but STA tools hate combinational loops. Actual physical latches are built using cross-coupled inverters and transmission gates.
Q61 What is a Demultiplexer (DEMUX)?

Answer: A DEMUX does the exact reverse of a MUX. It takes a single input data line and routes it to one of $2^N$ output lines, based on the value of $N$ select lines. The unselected output lines are forced to 0.

Q62 Can a MUX act as a Parallel-to-Serial converter?

Answer: Yes. If you apply an N-bit parallel word to the data inputs of a MUX, and connect a sequential binary counter to the select lines, the MUX will output the data bits serially one-by-one on each clock cycle.

Q63 How is a MUX physically implemented at the transistor level in CMOS?

Answer: While it can be built using standard AND/OR logic gates, modern VLSI physically builds MUXes using Transmission Gates (TG). A 2:1 MUX requires only 2 TGs (4 transistors total + an inverter for the select line), drastically reducing silicon area compared to standard NAND/NOR implementations.

Q64 What happens if the select line of a MUX toggles while the inputs are stable?

Answer: It can cause a Glitch. If $I_0 = 1$ and $I_1 = 1$, the output should theoretically stay 1. However, as the select line transitions from 0 to 1, the internal AND/OR gates might experience unequal propagation delays, causing the output to momentarily dip to 0 (a Static-1 Hazard).

5. Encoders & Decoders

Q65 What is a Decoder?

Answer: A combinational circuit that converts an N-bit binary input code into exactly $2^N$ output lines. For any given input combination, exactly ONE output line goes High (Active-High Decoder) or Low (Active-Low Decoder).

Q66 What is the fundamental logical relationship between a Decoder and Boolean algebra?

Answer: A Decoder generates ALL possible Minterms for its given inputs. An N-to-$2^N$ decoder is essentially a minterm generator. By feeding selected decoder outputs into a massive OR gate, you can implement ANY boolean function in Sum of Products (SOP) form.

Q67 Whiteboard How do you implement a Full Adder using a 3:8 Decoder?

Answer: A Full Adder has 3 inputs ($A, B, C_{in}$). A 3:8 Decoder generates minterms $m_0$ through $m_7$.
• Sum = $\Sigma m(1, 2, 4, 7)$. Connect decoder outputs 1, 2, 4, 7 to a 4-input OR gate.
• Carry Out = $\Sigma m(3, 5, 6, 7)$. Connect decoder outputs 3, 5, 6, 7 to a 4-input OR gate.

Q68 What is the difference between a Decoder and a Demultiplexer (DEMUX)?

Answer: They are physically the exact same hardware circuit!
• If you treat the inputs as an Address, it's a Decoder.
• If you tie the address inputs to the Select lines, and pump data into the global "Enable" pin, it acts as a DEMUX (routing the enable data to the selected output line).

Q69 How do you build a 4:16 Decoder using 3:8 Decoders?

Answer: Use TWO 3:8 Decoders with Enable pins.
1. Connect the lower 3 inputs ($A_0, A_1, A_2$) to both decoders in parallel.
2. Connect the MSB input ($A_3$) directly to the Enable pin of the second decoder.
3. Connect $A_3$ through a NOT gate to the Enable pin of the first decoder.

Q70 What is an Encoder?

Answer: The reverse of a decoder. It takes $2^N$ input lines (where only one is active at a time) and compresses them into an N-bit binary code. (One-Hot to Binary conversion).

Q71 What is the catastrophic flaw of a standard basic Encoder?

Answer: If TWO input lines go High simultaneously, the output binary code becomes completely corrupt (a logical OR of the two intended codes). It also outputs `00...0` if input 0 is active, OR if NO inputs are active, making it ambiguous.

Q72 How does a Priority Encoder fix this flaw?

Answer: A Priority Encoder assigns a strict hierarchy to its inputs (e.g., $D_3 > D_2 > D_1 > D_0$). If multiple inputs go High simultaneously, the encoder ignores the lower-priority inputs and outputs the binary code corresponding strictly to the highest-priority active input. It also features a "Valid" output pin to resolve the all-zero ambiguity.

Q73 What is the primary use case for a Priority Encoder in an SoC?

Answer: Interrupt Controllers (NVIC/GIC). When multiple hardware peripherals (UART, Timer, GPIO) trigger an interrupt request (IRQ) to the CPU at the exact same millisecond, the Priority Encoder ensures the CPU handles the most critical hardware fault first.

Q74 Write the Boolean equations for a 4:2 Priority Encoder (assuming $D_3$ has highest priority).

Answer: Let inputs be $D_3, D_2, D_1, D_0$ and outputs be $Y_1, Y_0$ and $V$ (Valid).
$V = D_3 + D_2 + D_1 + D_0$
$Y_1 = D_3 + D_2$
$Y_0 = D_3 + (D_1 \cdot D_2')$

Concept: For $Y_0$, $D_1$ is only allowed to drive the output High if the higher-priority $D_2$ is NOT active.
Q75 What is a BCD to 7-Segment Decoder?

Answer: A specialized combinational circuit that takes a 4-bit Binary Coded Decimal (BCD) input (values 0-9) and activates the specific combinations of 7 output lines needed to light up an LED digital display to show that decimal number.

6. Arithmetic Circuits (Adders & Comparators)

Q76 Write the Boolean equations for a Half Adder.
$Sum = A \oplus B$
$Carry = A \cdot B$

It takes two 1-bit inputs and cannot accept a carry-in from a previous stage.

Q77 Write the Boolean equations for a Full Adder.
$Sum = A \oplus B \oplus C_{in}$
$C_{out} = (A \cdot B) + (C_{in} \cdot (A \oplus B))$
Q78 How do you build a Full Adder using Half Adders?

Answer: It takes exactly Two Half Adders and one OR gate.
1. First Half Adder adds $A$ and $B$, generating $Sum_1$ and $Carry_1$.
2. Second Half Adder adds $Sum_1$ and $C_{in}$, generating the final $Sum$ and $Carry_2$.
3. The final $C_{out}$ is generated by passing $Carry_1$ and $Carry_2$ through an OR gate.

Q79 What is a Ripple Carry Adder (RCA), and what is its fundamental flaw?

Answer: An RCA cascades $N$ Full Adders in series to add $N$-bit numbers. The $C_{out}$ of bit 0 feeds into the $C_{in}$ of bit 1.
Flaw: Delay scales linearly $O(N)$. The final MSB cannot compute its sum until the carry ripples sequentially through every single previous bit. For a 32-bit RCA, the critical path is massive, heavily restricting clock frequency.

Q80 How does a Carry Look-Ahead Adder (CLA) solve the RCA delay problem?

Answer: It computes the Carry signals for ALL bits simultaneously in parallel using Generate ($G$) and Propagate ($P$) logic, rather than waiting for them to ripple. This reduces the delay from $O(N)$ to theoretically $O(\log N)$, trading a massive increase in silicon area (for complex logic gates) to achieve high speed.

Q81 Define the Propagate ($P_i$) and Generate ($G_i$) terms in a CLA.

Answer:
• Generate ($G_i = A_i \cdot B_i$): This bit stage will generate a Carry-out of 1 regardless of what the Carry-in is.
• Propagate ($P_i = A_i \oplus B_i$): This bit stage will propagate an incoming Carry-in to the Carry-out ($C_{out} = C_{in}$).

$C_{i+1} = G_i + (P_i \cdot C_i)$
Q82 Write the equations for a Half Subtractor.
$Difference = A \oplus B$
$Borrow = A' \cdot B$

Notice the Difference logic is exactly identical to the Sum logic of a Half Adder.

Q83 Tricky How do CPUs perform subtraction without having dedicated Subtractor circuits?

Answer: They use 2's Complement Addition. A Subtractor is a waste of silicon. To compute $A - B$, the CPU simply inverts all the bits of $B$ (using NOT gates) and sets the initial $C_{in}$ of the Adder to $1$. This mathematically creates the 2's complement of $B$, transforming the operation into $A + (-B)$.

Q84 How do you build an Adder/Subtractor combined unit?

Answer: Place XOR gates on the $B$ inputs of an N-bit Adder, and tie the other leg of the XOR gates to a global `Control` pin. Also, tie the $C_{in}$ of the first stage to that `Control` pin.
• Control = 0 (Add): $B \oplus 0 = B$, and $C_{in} = 0$. Circuit does $A + B$.
• Control = 1 (Sub): $B \oplus 1 = B'$, and $C_{in} = 1$. Circuit does $A + B' + 1$ (2's complement subtraction!).

Q85 What is a Carry Save Adder (CSA)?

Answer: Used when adding 3 or more numbers together (like in a Multiplier). Instead of rippling the carry, a CSA takes 3 inputs ($X, Y, Z$) and immediately outputs two vectors: a Sum vector and a Shifted Carry vector. These two vectors are only added together using a standard CLA at the very last step. This breaks the critical path delay of chained adders.

Q86 What logic gate forms the core of a Digital Multiplier?

Answer: The AND gate. In binary, multiplying a bit by a bit ($1 \times 1 = 1$, $1 \times 0 = 0$) is exactly the logical AND operation. A multiplier generates partial products using an array of AND gates, then adds those partial products using CSAs and CLAs.

Q87 How many bits is the output of an $N$-bit by $M$-bit multiplier?

Answer: The result is strictly $N + M$ bits wide to prevent overflow. (e.g., Multiplying two 32-bit numbers requires a 64-bit result register).

Q88 What is a Magnitude Comparator?

Answer: A combinational circuit that compares two N-bit binary numbers $A$ and $B$, and outputs three signals: $A > B$, $A = B$, and $A < B$.

Q89 Write the logic for a 1-bit Comparator.

Answer:
• Equal ($A = B$): $A \odot B$ (XNOR)
• Greater ($A > B$): $A \cdot B'$
• Less ($A < B$): $A' \cdot B$

Q90 In a Multi-bit Comparator, in what order are the bits checked?

Answer: From MSB to LSB. The Most Significant Bits dictate magnitude. If $A_{msb} > B_{msb}$, the entire number $A$ is greater, and the lower bits are completely ignored.

7. Combinational Logic Whiteboard Puzzles

Q91 Whiteboard Can you build a 2-input AND gate using only 2-input NOR gates? How many?

Answer: Yes, it requires 3 NOR gates.
De Morgan's: $A \cdot B = (A' + B')'$.
1. Generate $A'$ using NOR(A,A).
2. Generate $B'$ using NOR(B,B).
3. Feed $A'$ and $B'$ into the final NOR gate.

Q92 Whiteboard A room has 3 light switches ($A, B, C$). Toggling ANY single switch must turn the light on/off. Write the boolean equation.

Answer: This is the definition of an Odd Parity generator.
Equation: $Light = A \oplus B \oplus C$.
Whenever exactly one (or all three) switches are flipped (1), the output changes state.

Q93 Whiteboard How do you detect if a 4-bit number is a power of 2?

Answer: A binary number is a power of 2 if it contains exactly a single '1' bit (e.g., 0001, 0010, 0100, 1000). You can detect this by checking if `(N & (N - 1)) == 0`. (Note: this also flags 0000 as true, so you must explicitly AND it with `(N != 0)`).

Q94 Whiteboard Implement a 3-input Majority Gate (Outputs 1 if at least two inputs are 1).

Answer:
Equation: $Y = AB + BC + AC$.
This exact logic is used as the Carry-Out generation logic in a Full Adder.

Q95 Whiteboard Why does $A \oplus B \oplus A \oplus B = 0$?

Answer: Because XOR is associative and commutative. You can rearrange it as $(A \oplus A) \oplus (B \oplus B)$. Since any signal XORed with itself is 0, the equation reduces to $0 \oplus 0 = 0$.

Q96 How do you double a binary number without using an Adder or Multiplier?

Answer: Apply a Logical Left Shift by 1 bit. Appending a '0' to the LSB mathematically multiplies any binary number by exactly 2.

Q97 How do you divide an unsigned binary number by 2?

Answer: Apply a Logical Right Shift by 1 bit. The LSB is dropped, and a 0 is inserted at the MSB.

Q98 Tricky How do you divide a SIGNED (2's complement) binary number by 2?

Answer: Apply an Arithmetic Right Shift (>>>). You cannot just insert a 0 at the MSB. You must replicate the existing MSB (the sign bit) to preserve the negative sign while shifting.

Q99 If you have an N-bit Ripple Carry Adder, what is the critical path?

Answer: The critical path runs from the $A_0, B_0, C_{in}$ inputs of the LSB Half-Adder, through the Carry generation logic of every intermediate Full Adder, arriving finally at the Sum logic of the MSB Full Adder. It traverses $N$ carry stages.

Q100 The Final Test: Swap the values of two variables A and B using strictly combinational logic (no temporary register).

Answer: Use three cascaded XOR gates.
1. $A_{new} = A \oplus B$
2. $B_{new} = A_{new} \oplus B = (A \oplus B) \oplus B = A \oplus (B \oplus B) = A \oplus 0 = \mathbf{A}$.
3. $A_{final} = A_{new} \oplus B_{new} = (A \oplus B) \oplus A = (A \oplus A) \oplus B = 0 \oplus B = \mathbf{B}$.

Trap: While this works perfectly on a whiteboard or software, in physical hardware (Verilog), doing this combinationally creates a massive delay and potential glitches. In hardware, you should just swap wires directly (`assign {A, B} = {B, A}`) without using gates at all!
