Chapter 1: Digital Electronics

The foundation of ASIC design. Master Combinational Logic, Sequential Circuits, and FSMs.

1. Logic Gates & Universal Logic

Concept: Logic gates are the basic building blocks of any digital system. NAND and NOR are called Universal Gates because any boolean function (AND, OR, NOT, XOR) can be implemented using only NAND or only NOR gates.

Interview Question

Q: Why do we prefer NAND gates over NOR gates in standard cell libraries?

The Satisfying Answer: "NAND gates are generally preferred because they use series NMOS transistors and parallel PMOS transistors. Because electrons (majority carriers in NMOS) have roughly 2 to 3 times higher mobility than holes (in PMOS), NMOS transistors are faster. In a NOR gate, the slower PMOS transistors are in series, which significantly degrades the rise time and increases logical effort. Therefore, NAND gates offer better area-delay characteristics."

Follow-up Q: How many 2-input NAND gates are required to implement a 2-input XOR gate?

Answer: 4 NAND gates. \( Y = A \oplus B \)

2. Multiplexers (MUX)

Concept: A Multiplexer is a data selector. It routes one of \( 2^N \) inputs to a single output based on \( N \) select lines. It is a universal combinational circuit; a \( 2^N:1 \) MUX can implement any \( N+1 \) variable boolean function.

2:1 MUX Implementation

Equation: Y = S'·I0 + S·I1

Interview Question

Q: Implement a 2-input AND gate using a 2:1 MUX.

The Satisfying Answer: "For a 2-input AND gate, the equation is \( Y = A \cdot B \). We connect input A to the select line (S). When S=0 (A=0), the output should be 0, so we tie I0 to Ground (0). When S=1 (A=1), the output should be B, so we connect I1 to B. Thus, Y = A'·0 + A·B = A·B."

Common Mistake: Overcomplicating Shannon's expansion. Always use one variable as the select line and observe what the remaining function reduces to (0, 1, the other variable, or its complement).

3. Sequential Logic: Latches vs Flip-Flops

Concept: Combinational logic output depends only on present inputs. Sequential logic has memory—output depends on present inputs and past states.

  • Latch: Level-sensitive. Transparent when the clock is high (or low).
  • Flip-Flop: Edge-triggered. Samples data only at the rising (or falling) edge of the clock. A standard D Flip-Flop is built using two back-to-back latches (Master-Slave configuration).
Interview Question

Q: If Latches can cause timing issues, why do we ever use them instead of Flip-Flops?

The Satisfying Answer: "While Flip-Flops are safer for synchronous design and easier for EDA tools to analyze, latches use fewer transistors, saving area and power. More importantly, latches allow for Time Borrowing. If a combinational path is too slow, a latch allows it to 'borrow' time from the next clock cycle while it remains transparent, which is a technique used in high-performance CPU pipelines to achieve higher clock frequencies."

4. Finite State Machines (FSMs)

Moore Machine

Output depends ONLY on the current state.

  • More states required.
  • Outputs are synchronous (change only on clock edge).
  • Safer design, no combinational loops to outputs.
Mealy Machine

Output depends on current state AND current inputs.

  • Fewer states generally required.
  • Output can change asynchronously with inputs (glitch risk).
  • Responds faster to input changes.
Interview Question

Q: Design a sequence detector to detect "1011" (overlapping allowed). How many states are needed for a Moore vs Mealy machine?

The Satisfying Answer: "For a sequence of length N (N=4 here):
A Moore machine will require N + 1 = 5 states, because the output is associated directly with reaching the final state.
A Mealy machine will require exactly N = 4 states, because the output goes high on the transition from the 3rd state to the 1st state upon receiving the final '1'."
