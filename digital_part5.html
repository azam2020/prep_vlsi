12. Clock Dividers (The Interviewer's Favorite)

Technical Explanation SoC designs require multiple clock domains. An external PLL might generate a 2 GHz clock, but your I2C peripheral only needs 10 MHz. Clock dividers shrink the frequency. Designing even dividers is easy. Designing odd dividers with exactly a 50% duty cycle separates the novices from the experts.

Divide by 2 (Even Divider)

Concept: A simple T-Flip-Flop or a D-Flip-Flop with inverted output (\( \bar{Q} \)) fed back to the D input.

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) clk_div2 <= 1'b0;
    else clk_div2 <= ~clk_div2;
end
Divide by 3 with 50% Duty Cycle

The Tricky Part: A standard Mod-3 counter gives a 33% or 66% duty cycle. To get 50%, you must utilize the negative edge of the source clock.

Architecture: 1. Create a Mod-3 counter on posedge clk (Flops A & B).
2. Create a third Flop (C) that samples Flop B on the negedge clk.
3. Final Output = B OR C. 

// Mod-3 counter (posedge)
always @(posedge clk) begin
    if (rst) {q1, q0} <= 2'b00;
    else begin
        q0 <= ~q1 & ~q0;
        q1 <= q0;
    end
end

// Negedge flop
always @(negedge clk) begin
    if (rst) q2 <= 1'b0;
    else q2 <= q1;
end

// 50% duty cycle output
assign clk_out = q1 | q2;
Pro Tip for Fractional Dividers: If asked to divide a clock by 1.5, use a MUX. Generate a clock that pulses on posedge, another on negedge, and toggle the MUX select line to output alternate pulses.

13. Hazards, Glitches, and Metastability

Combinational Hazards

Hazards occur due to unequal propagation delays of signals through different paths in combinational logic.

  • Static-1 Hazard: Output is meant to stay 1, but momentarily dips to 0. (Fix: Add redundant Prime Implicant in K-Map).
  • Static-0 Hazard: Output is meant to stay 0, but momentarily spikes to 1.
  • Dynamic Hazard: Output is meant to change from 0 to 1, but bounces (0 → 1 → 0 → 1).

Metastability

Definition When a flip-flop's setup or hold time is violated, its output hovers at an intermediate voltage level (neither logic 0 nor 1) before eventually resolving to a random state. This is called metastability.

MTBF (Mean Time Between Failures)

The probability of failure due to metastability is calculated using the MTBF equation:

\( \text{MTBF} = \frac{e^{t_r / \tau}}{T_0 \cdot f_{clk} \cdot f_{data}} \)

Where \( t_r \) is the resolution time (slack available), \( \tau \) and \( T_0 \) are device constants, \( f_{clk} \) is clock frequency, and \( f_{data} \) is data toggle rate.

The Fix: We cannot eliminate metastability entirely, but we can increase MTBF to centuries by using a 2-Flip-Flop Synchronizer when crossing Clock Domains (CDC).

A negative hold time simply means that the data is allowed to change before the actual clock edge arrives at the external pin of the flip-flop. This happens when the internal clock path inside the flip-flop has a longer delay (due to internal buffers/inverters) than the internal data path.

Essentially, the clock reaches the internal latch mechanism later than the data does, so from the outside world's perspective, the data can change slightly before the clock edge without causing a violation.

There are 3 possible remainders: 0, 1, and 2. Therefore, we need 3 states: S0, S1, S2.
When a new bit 'x' arrives, the new number formed is \( 2 \times (\text{old number}) + x \).
The new remainder is \( (2 \times \text{old\_remainder} + x) \pmod 3 \).

  • State S0 (Rem 0): If input is 0 → New Rem is (0+0)%3 = 0 (Stay S0). If 1 → (0+1)%3 = 1 (Go to S1).
  • State S1 (Rem 1): If input is 0 → (2+0)%3 = 2 (Go to S2). If 1 → (2+1)%3 = 0 (Go to S0).
  • State S2 (Rem 2): If input is 0 → (4+0)%3 = 1 (Go to S1). If 1 → (4+1)%3 = 2 (Stay S2).

Output is '1' whenever the FSM is in state S0.

Why: To save dynamic power. If a block of logic is idle, turning off its clock prevents the flip-flops from toggling, saving \( P = \alpha C V^2 f \).

Glitch-Free Design: You cannot simply use an AND gate (Clk AND Enable), because if Enable changes while Clk is HIGH, the output clock will glitch.

Solution: Use an Integrated Clock Gating (ICG) cell. This consists of a Negative-level Latch followed by an AND gate. The Enable signal is passed through the negative latch, ensuring it only changes when the Clock is LOW. Thus, the AND gate output never glitches mid-cycle.

Imagine a Flip-Flop is a camera taking a photo of a moving car (the data).

  • Setup Time: The car must be perfectly still inside the frame for a few milliseconds before the camera flash goes off, so the picture isn't blurry on the leading edge.
  • Hold Time: The car must remain completely still for a few milliseconds after the flash goes off, ensuring the camera shutter has fully closed and doesn't capture motion blur on the trailing edge.

A Ring Oscillator is constructed using an ODD number of inverters connected in a closed loop. (Using an even number creates a stable latch/SRAM cell, not an oscillator).

Frequency Equation:
\( f = \frac{1}{2 \times N \times t_d} \)
Where \( N \) is the number of inverters (must be odd, e.g., 3, 5, 7) and \( t_d \) is the propagation delay of a single inverter. It is heavily used in silicon manufacturing to test the speed of a particular wafer batch.

Setup Violation Fixes (Data is arriving too late):
- Decrease the clock frequency (easiest logic fix).
- Reduce the combinational logic delay (use faster gate variants, lower Vt cells).
- Pipeline the design (insert a flip-flop in the middle of the combinational logic).
- Route the clock line to arrive slightly later at the destination FF (Useful Skew).

Hold Violation Fixes (Data is arriving too fast):
- You cannot fix a hold violation by changing the clock frequency! Hold time is evaluated at the exact same clock edge.
- Insert delay buffers in the data path to slow the data down.
- Use slower gate variants (higher Vt cells) in the data path.

We know \( A \cdot B = (A' + B')' \).
The outer complement with a sum is a NOR operation. The inner complements are NOT gates.
1. Create a NOT gate for A by tying inputs of a NOR gate together: NOR(A, A) = A'.
2. Create a NOT gate for B: NOR(B, B) = B'.
3. Feed A' and B' into a third NOR gate: NOR(A', B') = (A' + B')' = A · B.
Requires exactly 3 NOR gates.

LFSR (Linear Feedback Shift Register) is a shift register whose input bit is a linear function (usually XOR) of its previous state.

Uses:
1. Generating Pseudo-Random Number sequences (PRBS).
2. Used heavily in Design-for-Test (DFT) for BIST (Built-In Self-Test) pattern generation and signature analysis.
3. Cryptography and data scrambling (like in PCIe or USB protocols to prevent long strings of 0s or 1s that cause loss of clock sync).

Clock Skew is the spatial variation in arrival time of a clock signal at different flip-flops across the chip due to routing wire lengths and buffer delays.

Positive Skew (Destination clock arrives later): Helps with Setup Time but hurts Hold Time.
Negative Skew (Destination clock arrives earlier): Hurts Setup Time but helps Hold Time.

It is NOT always bad. Physical Design engineers intentionally introduce skew (called Useful Skew) to borrow time from a fast logic path and give it to a slow logic path, fixing setup violations.
