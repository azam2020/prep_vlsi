Chapter 1: Digital Electronics (Part 3/4)

Flip-Flops, Counters, and Shift Registers

6. Flip-Flops & Memory Elements

Definition Edge-triggered memory elements that store one bit of data. The state only changes at the rising or falling edge of a clock signal.

Simple Explanation If a latch is a door that stays open as long as you hold the handle, a flip-flop is a revolving door that only lets one person through at the exact moment a bell rings (the clock edge).

Technical Explanation 99% of VLSI design relies on the **D-type Flip-Flop (D-FF)**. A standard positive-edge D-FF is constructed using two latches in series (Master-Slave configuration) with inverted clocks. The Master catches the data when the clock is low, and passes it to the Slave to output when the clock goes high, preventing transparency (race conditions) from input to output.

Master-Slave D Flip-Flop Concept

Master is transparent on CLK=0. Slave is transparent on CLK=1.

Verilog: D-FF with Async Active-Low Reset
module dff (
    input clk,
    input rst_n, // Active-low reset
    input d,
    output reg q
);
    // Sensitivity list dictates edge-triggering
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q <= 1'b0;  // Non-blocking assignment!
        else
            q <= d;
    end
endmodule
The Interview Scenario

Interviewer: "How do you convert a D Flip-Flop into a T (Toggle) Flip-Flop using only basic gates?"

Your Satisfying Answer: "A T Flip-Flop toggles its output when T=1 and holds its output when T=0. The characteristic equation of a T-FF is \( Q_{next} = T \oplus Q \). Since a D Flip-Flop just passes its input to the output (\( Q_{next} = D \)), I simply need to make \( D = T \oplus Q \). So, I would take the Q output of the D-FF, feed it into a 2-input XOR gate along with the T signal, and connect the output of that XOR gate into the D input pin."

Follow-up Q: "What if you just want it to act as a divide-by-2 frequency divider?"

Answer: "If I just need a divide-by-2 circuit, that means it should toggle on every single clock cycle (T=1 always). If T=1, \( D = 1 \oplus Q = Q' \). So, I don't even need an XOR gate. I just connect the \( \bar{Q} \) (Q-bar) output directly back into the D input."

Common Mistake: Using blocking assignments (`=`) instead of non-blocking (`<=`) inside a sequential `always` block in Verilog. This can simulate correctly sometimes, but will infer incorrect hardware (like unintended latches or wrong shift register cascades) during synthesis.

7. Counters

Technical Explanation Counters are state machines that cycle through a specific sequence of states. They are broadly classified into two categories:

FeatureAsynchronous (Ripple) CounterSynchronous Counter
ClockingCLK only feeds the first FF. The output of one FF acts as the CLK for the next.Same CLK feeds all FFs simultaneously.
Speed/DelaySlower. Delays accumulate (Propagation delay = \( N \times t_{pd} \)).Faster. Delay is just the delay of one FF + logic.
GlitchingHigh risk of decoding glitches due to intermediate states.Clean state transitions, safe for decoding.
VLSI UsageRarely used (except for specific low-power clock dividers).Industry Standard for FSMs and timers.
Ring vs. Johnson Counters

These are built using shift registers and are very common in interviews.

Ring Counter

Connect the Q of the last FF back to the D of the first FF. Requires a preset state (e.g., 1000).

  • States used: N (for N flip-flops)
  • Sequence (4-bit): 1000 → 0100 → 0010 → 0001
  • Pro: Decoding requires NO logic gates.
Johnson (Twisted Ring) Counter

Connect the \( \bar{Q} \) of the last FF back to the D of the first FF. Initializes at 0000.

  • States used: 2N (for N flip-flops)
  • Sequence (4-bit): 0000 → 1000 → 1100 → 1110 → 1111 → 0111...
  • Pro: More states per FF. Decoding needs only 2-input AND gates.
The Interview Scenario

Interviewer: "Why do we strictly avoid Ripple Counters in modern SoC design?"

Your Satisfying Answer: "Ripple counters cause severe Timing Analysis issues. Because the output of one flip-flop acts as the clock for the next, there is massive clock skew across the bits. If you try to sample the counter's value using the main system clock, you risk sampling during a transition (causing setup/hold violations and metastability). Furthermore, intermediate 'garbage' states appear momentarily as the ripple propagates, which will cause false triggers if those bits are used in combinational logic."

8. Shift Registers

Definition A group of cascaded flip-flops used to store and shift binary data left or right upon every clock cycle.

Simple Explanation Think of a bucket brigade at a fire. Person A hands the bucket to Person B, Person B hands it to Person C. Data moves one spot over on every tick of the clock.

  • SISO (Serial In, Serial Out): Used for adding delay to a signal (Delay Lines).
  • SIPO (Serial In, Parallel Out): Used to convert a serial data stream (like UART/SPI) into parallel data (a byte) for the CPU to read.
  • PISO (Parallel In, Serial Out): Used to convert CPU parallel bytes into a serial bit stream to transmit over a wire.
  • PIPO (Parallel In, Parallel Out): Simply acts as a data register (memory).
Real Interview Tip: If an interviewer asks you to "multiply a binary number by 4 without using a multiplier block," the answer is to use a Shift Register. Shifting data left by 1 bit multiplies it by 2. Shifting left by 2 bits multiplies it by 4. Shifting right divides by 2. This is called a barrel shifter in CPU ALUs.
