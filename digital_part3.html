Chapter 1: Digital Electronics — Part 3 (Q101 to Q150)

Sequential Logic: Latches, Flip-Flops, Shift Registers, and Counters

8. Latches & Flip-Flops

Q101 What is the fundamental difference between Combinational and Sequential logic?

Answer: Combinational logic output depends only on the present inputs (has no memory). Sequential logic output depends on the present inputs AND the past sequence of inputs (has memory/feedback).

Q102 What is the difference between a Latch and a Flip-Flop?

Answer:
• Latch: Level-sensitive. It is "transparent" and passes data continuously as long as the enable/clock signal is asserted (High or Low).
• Flip-Flop: Edge-triggered. It only captures and passes data at the exact instantaneous moment the clock transitions (Rising Edge or Falling Edge).

Q103 What is an SR Latch? Write its Truth Table.

Answer: A Set-Reset Latch is the most basic memory element, built using two cross-coupled NOR gates or NAND gates.
• $S=0, R=0$: Hold State ($Q_{next} = Q_{prev}$)
• $S=1, R=0$: Set State ($Q_{next} = 1$)
• $S=0, R=1$: Reset State ($Q_{next} = 0$)
• $S=1, R=1$: Invalid / Race Condition

Q104 Why is $S=1, R=1$ invalid in a NOR-based SR Latch?

Answer: If both Set and Reset are 1, both NOR gates are forced to output 0. This violates the fundamental rule that outputs $Q$ and $\bar{Q}$ must be logical complements. Furthermore, if both inputs transition back to 0 simultaneously, the latch enters a metastable race condition and its final state becomes unpredictable.

Q105 How does a D-Latch solve the SR Latch's invalid state?

Answer: A D-Latch ties the $S$ and $R$ inputs together through an inverter ($S = D$, $R = D'$). This guarantees that $S$ and $R$ can never be 1 at the same time, completely eliminating the invalid $1,1$ state. The output simply follows $D$ when enabled.

Q106 How do you build a positive edge-triggered D Flip-Flop using Latches?

Answer: Using a Master-Slave configuration. You cascade two D-Latches in series.
• The Master latch is enabled when $CLK = 0$.
• The Slave latch is enabled when $CLK = 1$.

Master-Slave D-Flip-Flop Architecture

The Master catches data when CLK=0. The Slave passes it to Q when CLK transitions to 1.

Q107 Tricky Why does the Master-Slave configuration successfully create edge-triggering?

Answer: Because the two latches are enabled on opposite clock phases, they are never transparent at the same time.
• When $CLK=0$, Master sees $D$, but Slave is locked.
• When $CLK \uparrow 1$, Master instantly locks (ignoring any new $D$ changes), and Slave opens to pass the locked Master data to $Q$. This perfectly mimics instantaneous edge-triggering.

Q108 What is a JK Flip-Flop, and how does it improve upon the SR Flip-Flop?

Answer: A JK Flip-Flop resolves the invalid state of the SR Flip-Flop.
When $J=1, K=1$, instead of entering a race condition, the flip-flop toggles its state ($Q_{next} = Q_{prev}'$). This makes it highly versatile for building counters.

Q109 What is the "Race Around Condition" in a JK Latch?

Answer: If a Level-Sensitive JK Latch has $J=1, K=1$, it will toggle. However, if the clock pulse width (time the clock is High) is longer than the propagation delay of the latch, the latch will toggle, feed its new output back to its inputs, and toggle again, oscillating wildly until the clock falls.
Fix: Use an Edge-Triggered Master-Slave JK Flip-Flop.

Q110 Write the characteristic equations for D, T, and JK Flip-Flops.
D-FF: $Q_{next} = D$
T-FF: $Q_{next} = T \oplus Q$
JK-FF: $Q_{next} = J Q' + K' Q$
Q111 Whiteboard How do you convert a D Flip-Flop into a T Flip-Flop?

Answer: A T-FF toggles when $T=1$. Characteristic eq: $Q_{next} = T \oplus Q$.
Since a D-FF passes its input directly ($Q_{next} = D$), we set $D = T \oplus Q$.
Implementation: Connect an XOR gate to the D input. The inputs to the XOR gate are the $T$ signal and the $Q$ output of the flip-flop.

Q112 Whiteboard How do you convert a JK Flip-Flop into a D Flip-Flop?

Answer: A D-FF must set when $D=1$ and reset when $D=0$.
Connect $D$ directly to the $J$ pin. Connect an inverted $D$ ($D'$) to the $K$ pin.
If $D=1 \rightarrow J=1, K=0 \rightarrow Q=1$.
If $D=0 \rightarrow J=0, K=1 \rightarrow Q=0$.

Q113 What is the Excitation Table of a Flip-Flop?

Answer: A Truth Table tells you the next state based on current inputs. An Excitation Table works backward: it tells you what inputs you need to apply to force a specific state transition (from $Q_{prev}$ to $Q_{next}$). It is the primary tool for designing state machines and counters.

Q114 Write the Excitation Table for a T Flip-Flop.

Answer:
• $0 \rightarrow 0$: Require $T = 0$
• $0 \rightarrow 1$: Require $T = 1$ (Toggle)
• $1 \rightarrow 0$: Require $T = 1$ (Toggle)
• $1 \rightarrow 1$: Require $T = 0$

Q115 Write the Excitation Table for a JK Flip-Flop.

Answer: (X = Don't Care)
• $0 \rightarrow 0$: $J = 0, K = X$
• $0 \rightarrow 1$: $J = 1, K = X$
• $1 \rightarrow 0$: $J = X, K = 1$
• $1 \rightarrow 1$: $J = X, K = 0$

9. Shift Registers

Q116 What is a Shift Register?

Answer: A cascade of Flip-Flops sharing the same clock, where the output $Q$ of one flip-flop is connected to the input $D$ of the next. Upon every clock cycle, the stored data shifts one position left or right.

Q117 Define the 4 main types of Shift Registers.

Answer:
1. SISO: Serial In, Serial Out (Used for data delay lines).
2. SIPO: Serial In, Parallel Out (Used to convert UART serial stream into a byte).
3. PISO: Parallel In, Serial Out (Used to transmit a CPU byte over a single wire).
4. PIPO: Parallel In, Parallel Out (Basically a standard memory register).

Q118 How does a PISO (Parallel-In Serial-Out) register work?

Answer: It uses 2:1 MUXes at the D-input of every flip-flop, controlled by a Shift/Load signal.
• When Load=1: The MUX connects external parallel data to the D-pins. All FFs load the data simultaneously in 1 clock cycle.
• When Shift=0: The MUX connects the $Q$ of the previous FF to the $D$ of the next FF, shifting the data out serially.

Q119 What is a Universal Shift Register?

Answer: A bidirectional shift register capable of shifting left, shifting right, parallel loading, and holding state. It typically uses 4:1 MUXes at the input of every flip-flop to select between the 4 operational modes.

Q120 How can a Shift Register be used for arithmetic operations?

Answer: Shifting a binary number left by 1 bit multiplies it by 2. Shifting right by 1 bit divides it by 2. This is implemented in CPU ALUs as a "Barrel Shifter," which can execute massive multiplications much faster than an adder array.

Q121 What is a Ring Counter?

Answer: A shift register where the output of the last flip-flop is fed directly back into the input of the first flip-flop. It recirculates a single '1' bit (e.g., 1000 $\rightarrow$ 0100 $\rightarrow$ 0010 $\rightarrow$ 0001 $\rightarrow$ 1000). It requires a Preset to initialize the '1'.

Q122 What is the modulus of an N-bit Ring Counter, and what is its primary advantage?

Answer:
• Modulus: $N$. An N-bit ring counter yields $N$ unique states.
• Advantage: The states are inherently "One-Hot" encoded. Decoding a specific state requires ZERO logic gates; you just tap the $Q$ output of the specific flip-flop.

Q123 What is a Johnson Counter (Twisted Ring Counter)?

Answer: A shift register where the inverted output ($\bar{Q}$) of the last flip-flop is fed back to the input of the first flip-flop. It initializes at 0000.

4-bit Johnson Counter Architecture

Sequence: 0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000

Q124 What is the modulus of an N-bit Johnson Counter?

Answer: $2N$. A 4-bit Johnson counter yields exactly 8 unique states. It is twice as efficient in state usage as a Ring Counter, while still maintaining highly simple decoding logic.

Q125 Tricky How many inputs must the decoding AND gates have to decode a Johnson Counter state?

Answer: Exactly Two inputs. Regardless of whether it's a 4-bit, 10-bit, or 100-bit Johnson counter, every unique state can be identified by checking exactly two adjacent flip-flops using a 2-input AND gate. This is a massive hardware savings over decoding a standard binary counter.

10. Counters (Asynchronous & Synchronous)

Q126 What is the difference between an Asynchronous (Ripple) Counter and a Synchronous Counter?

Answer:
• Ripple Counter: Only the first FF receives the external clock. The output ($Q$) of the first FF acts as the clock for the second FF, and so on.
• Synchronous Counter: All FFs receive the exact same external clock simultaneously. Next states are calculated via combinational logic fed into the $D$ or $T$ pins.

Q127 Why are Ripple Counters strictly avoided in modern VLSI design?

Answer: Glitches and Skew. Because the clock ripples through the FFs, the MSB updates much later than the LSB. During this rippling time, the counter momentarily outputs "garbage" intermediate states (e.g., transitioning 011 $\rightarrow$ 100 might briefly output 010, 000). If this output is decoded, it causes fatal logic glitches.

Q128 What is the propagation delay of an N-bit Ripple Counter?

Answer: $Delay = N \times t_{pd\_ff}$. The total delay is the sum of the clock-to-Q delays of all $N$ flip-flops in the chain.

Q129 What is the propagation delay of an N-bit Synchronous Counter?

Answer: $Delay = t_{pd\_ff} + t_{comb}$. Because all FFs are clocked simultaneously, the delay does not scale with $N$. It is simply the delay of one flip-flop plus the delay of the largest combinational AND-gate tree used to generate the next-state logic.

Q130 What is a Modulo-N (Mod-N) Counter?

Answer: A counter that has exactly $N$ unique states. It counts from $0$ to $N-1$, and on the next clock cycle, it resets back to $0$. A standard 3-bit binary counter is naturally a Mod-8 counter.

Q131 Numerical How many Flip-Flops are required to build a Mod-100 Counter?

Answer: The formula is $2^K \ge N$.
For $N = 100$: $2^6 = 64$ (Not enough). $2^7 = 128$ (Enough).
7 Flip-Flops are required.

Q132 What is a Decade (BCD) Counter?

Answer: A Mod-10 counter. It counts from $0000$ (0) to $1001$ (9). Upon reaching 9, the next clock cycle forces the counter to reset to 0000 instead of continuing to 1010 (10).

Q133 Whiteboard How do you force a 3-bit Synchronous Counter to act as a Mod-6 counter (0 to 5) using an asynchronous clear?

Answer: The counter must reset when it hits State 6 (110).
Connect $Q_2$ (MSB) and $Q_1$ to a NAND gate. Feed the output of the NAND gate to the Active-Low `Clear` pins of all Flip-Flops. The moment the counter hits 110, the NAND outputs 0, instantly wiping the FFs back to 000.

Q134 How does a Synchronous Up/Down Counter work?

Answer: It uses a control pin `M` (Mode).
• Up (M=0): The $T$ inputs of the FFs are driven by the $Q$ outputs of previous stages.
• Down (M=1): The $T$ inputs of the FFs are driven by the inverted $\bar{Q}$ outputs of previous stages.

Q135 What is a "Lockout" condition in a counter?

Answer: If a Mod-5 counter (using 3 FFs) accidentally enters an unused state (like 111) due to noise or a power spike, and the next-state logic maps 111 $\rightarrow$ 110 $\rightarrow$ 111, the counter is trapped infinitely in unused states. This is a fatal lockout.

Q136 How do you design a "Self-Starting" counter?

Answer: You explicitly design the combinational next-state logic so that all unused states map to a valid state (typically 000). If the counter glitches into 111, the next clock edge mathematically forces it back into the primary 0-to-N loop.

Q137 What is an LFSR (Linear Feedback Shift Register)?

Answer: A shift register where the input bit is driven by the XOR (linear function) of specific tap outputs. It cycles through a pseudo-random sequence of states. It is heavily used in cryptography, CRC generation, and PRPGs for Logic BIST.

Q138 What is a Maximal-Length LFSR?

Answer: An N-bit LFSR that cycles through exactly $2^N - 1$ unique states before repeating. (It misses the all-zero state, because $0 \oplus 0 = 0$, which would lock the LFSR forever).

11. Clock Dividers & Tricky Sequential Puzzles

Q139 Whiteboard How do you create a Divide-by-2 Clock Divider?

Answer: Use a single D-Flip-Flop. Connect the inverted output $\bar{Q}$ back into the $D$ input. The FF will toggle on every rising edge of the source clock, producing an output clock with exactly half the frequency and a perfect 50% duty cycle.

Q140 Whiteboard How do you create a Divide-by-4 Clock Divider?

Answer: Cascade two Divide-by-2 circuits. Take the $Q$ output of the first D-FF and feed it into the `CLK` pin of the second D-FF. The output of the second FF is $f / 4$.

Q141 Tricky Can you use an asynchronous counter (Ripple counter) as a clock divider?

Answer: Technically yes; the $Q$ outputs of a ripple counter are exact powers-of-two clock divisions ($f/2, f/4, f/8$). However, in ASIC design, driving clock pins with logic outputs creates severe clock skew and makes STA analysis a nightmare. It is generally avoided in favor of synchronous clock enables.

Q142 Whiteboard Explain the logic to create a Divide-by-3 Clock Divider with a perfectly 50% Duty Cycle.

Answer: A synchronous Mod-3 counter on the rising edge will give a 33% or 66% duty cycle. To achieve 50%, you MUST use the negative edge.
1. Create a Mod-3 counter ($Q_0, Q_1$) clocked on the Rising Edge.
2. Add a third FF ($Q_2$) that samples $Q_1$ on the Falling Edge.
3. The final divided clock is $Q_1 \text{ OR } Q_2$.

Q143 How do you design a sequence detector to detect the pattern "101" (overlapping allowed) using a Shift Register?

Answer: You do not need a complex FSM! Feed the serial data into a 3-bit SISO Shift Register. Tap the outputs of the three FFs ($Q_2, Q_1, Q_0$) and feed them into an AND gate tailored to the pattern: `assign matched = Q_2 & ~Q_1 & Q_0;`. It checks the last 3 bits instantly.

Q144 What is the oscillation frequency of an N-stage Ring Oscillator?
$f = \frac{1}{2 \cdot N \cdot t_{pd}}$

Where $N$ is an ODD number of inverters, and $t_{pd}$ is the propagation delay of a single inverter.

Q145 What happens if you build a Ring Oscillator using an EVEN number of inverters?

Answer: It will NOT oscillate. It will act as a bistable memory element (a latch/SRAM cell) and immediately lock into a stable DC state (either 1-0-1-0 or 0-1-0-1).

Q146 Tricky What must the initial state of a 4-bit Ring Counter be to work correctly?

Answer: It MUST be initialized to `1000` (or `0100`, `0010`, `0001`). If you initialize it to `0000`, it will just shift zeros forever and remain locked at `0000`.

Q147 What must the initial state of a Johnson Counter be?

Answer: It initializes safely at `0000`. Because the feedback is inverted, the 0 at the end becomes a 1 at the beginning, filling the register with 1s (`1000`, `1100`, `1110`...) before flushing them out with 0s.

Q148 Can a Shift Register be used as an analog delay line?

Answer: No, a digital shift register can only delay a digital bit stream by an exact integer number of clock cycles ($Delay = N \times T_{clk}$). Analog delay lines use physical LC networks or transmission lines.

Q149 Numerical A 4-bit ripple counter is built using T-FFs. Each FF has a $t_{pd}$ of 10ns. What is the maximum frequency of the counter?

Answer: In a ripple counter, the clock must wait for the worst-case ripple through ALL flip-flops before the next clock edge arrives.
$T_{min} = 4 \times 10ns = 40ns$.
$F_{max} = 1 / 40ns = \mathbf{25 \text{ MHz}}$.

Q150 The Final Test: Why does a Flip-Flop go metastable at the transistor level?

Answer: A flip-flop contains two cross-coupled inverters forming a bistable loop. If data transitions at the exact moment the clock samples, the voltage trapped in the loop rests at exactly $V_{DD}/2$. Because both inverters are sitting perfectly at their switching threshold ($V_{in} = V_{out}$), their gain is high but the differential is zero. It hangs in this unstable equilibrium until thermal noise nudges the voltage slightly, allowing the positive feedback to finally snap it to VDD or GND.
